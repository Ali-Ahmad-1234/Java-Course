# Темы презентаций: Ядро Linux и модули ядра

Этот раздел содержит темы групповых презентаций. Каждая тема рассчитана на группу из 2–3 студентов.

## Общая информация

| Параметр | Значение |
|---|---|
| Формат работы | Групповая презентация (2–3 человека) |
| Продолжительность выступления | 10–15 минут |
| Количество слайдов | 15–25 слайдов |
| Язык презентации | Русский |
| Формат файла | PDF или PPTX |

**Важно:** все участники группы должны принимать участие в выступлении и быть готовы ответить на вопросы по любой части презентации.

## Требования к презентации

- Презентация должна содержать примеры кода на языке C (модули ядра, системные вызовы и т.д.)
- Обязательны схемы и диаграммы, иллюстрирующие архитектуру
- Рекомендуется подготовить демонстрацию (видео или live-demo в виртуальной машине)
- Все утверждения должны быть подкреплены ссылками на источники

## Темы презентаций

| № | Тема | Основные вопросы для раскрытия |
|---|---|---|
| 1 | Архитектура ядра Linux | История и эволюция ядра; монолитное ядро vs микроядро vs гибридное; подсистемы ядра (процессы, память, VFS, сеть, драйверы); пространство ядра vs пользовательское пространство; механизм системных вызовов |
| 2 | Система сборки ядра Linux | Kconfig и инструменты конфигурации; иерархия Makefile и Kbuild; цикл сборки (menuconfig → make → modules → install); кросс-компиляция; управление конфигурацией (.config, defconfig) |
| 3 | Загружаемые модули ядра (LKM) | Структура модуля: module_init(), module_exit(), MODULE_LICENSE; Makefile для out-of-tree модулей; insmod, rmmod, lsmod, modinfo; параметры модулей; /proc/modules и /sys/module/ |
| 4 | Динамические загружаемые модули (DLKM) | Различие LKM и DLKM; modprobe и разрешение зависимостей; экспорт символов (EXPORT_SYMBOL); наложение модулей; автозагрузка через udev, чёрные списки |
| 5 | Драйверы символьных устройств | Классификация устройств; номера major/minor; структура file_operations; API cdev; создание узлов устройств |
| 6 | Драйверы блочных устройств | Блочные vs символьные устройства; gendisk и block_device_operations; очереди запросов и bio; планировщики I/O; RAM-диск как пример |
| 7 | Управление памятью в ядре | Адресное пространство и зоны памяти; buddy system; SLAB/SLUB/SLOB; vmalloc() vs kmalloc(); таблицы страниц, TLB, OOM killer |
| 8 | Планирование процессов | task_struct и состояния процесса; CFS и vruntime; политики реального времени; nice, приоритеты; CPU affinity |
| 9 | Виртуальная файловая система (VFS) | Архитектура VFS; superblock, inode, dentry, file; регистрация файловых систем; procfs и sysfs |
| 10 | Сетевой стек Linux | Архитектура стека; sk_buff; Netfilter и iptables/nftables; написание модуля фильтрации пакетов; сетевые драйверы |
| 11 | Модули безопасности ядра (LSM) | Архитектура LSM; SELinux; AppArmor; Linux capabilities; seccomp и seccomp-BPF |
| 12 | Отладка ядра и модулей | printk() и dmesg; ftrace; kprobes/kretprobes; KGDB/KDB; kdump и анализ crash-дампов |
| 13 | Механизмы синхронизации в ядре | Гонки данных в контексте ядра; спинлоки; мьютексы и семафоры; RCU; атомарные операции и барьеры памяти |
| 14 | Взаимодействие ядра и user space | Системные вызовы; ioctl; procfs/sysfs для обмена данными; Netlink-сокеты; mmap |
| 15 | Процесс загрузки Linux | BIOS vs UEFI; загрузчик GRUB2; инициализация ядра; initramfs/initrd; передача управления init-системе |
| 16 | Контейнеризация: Namespaces и Cgroups | Типы namespaces; unshare, nsenter; cgroups v1 vs v2; как Docker использует namespaces и cgroups; rootless-контейнеры |

## Полезные ресурсы

**Книги:**

- Linux Kernel Development — Robert Love (3rd Edition)
- Linux Device Drivers — Jonathan Corbet, Alessandro Rubini, Greg Kroah-Hartman (доступна бесплатно на lwn.net)
- Understanding the Linux Kernel — Daniel P. Bovet, Marco Cesati
- The Linux Programming Interface — Michael Kerrisk

**Онлайн-ресурсы:**

- The Linux Kernel Documentation — официальная документация ядра
- Linux Kernel Module Programming Guide
- LWN.net — новости и статьи о разработке ядра
- Kernel Newbies — ресурс для начинающих разработчиков ядра
- Bootlin Elixir Cross-Referencer — навигация по исходному коду ядра
- Linux Insides — подробное описание внутренностей ядра
