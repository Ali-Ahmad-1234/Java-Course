# Темы презентаций для 4-го модуля: Развёртывание Java-приложений

Этот раздел содержит темы групповых презентаций по сборке, развёртыванию и сопровождению Java-приложений. Каждая тема рассчитана на группу из 2–3 студентов.

## Общая информация

| Параметр | Значение |
|---|---|
| Формат работы | Групповая презентация (2–3 человека) |
| Продолжительность выступления | 10–15 минут |
| Количество слайдов | 15–25 слайдов |
| Язык презентации | Русский |
| Формат файла | PDF или PPTX |

**Важно:** все участники группы должны принимать участие в выступлении и быть готовы ответить на вопросы по любой части презентации.

## Краткий план работы

1. Выберите одну тему на группу и согласуйте её с преподавателем.
2. Объясните, какую задачу решает рассматриваемый способ развёртывания и в каких условиях он применяется.
3. Разберите конкретный пример. Можно использовать приложение Spring Boot из практических занятий 7 и 8 или минимальный учебный проект.
4. Поясните, как проверить результат. Если демонстрация подготовлена заранее, можно использовать снимок экрана, вывод команды или фрагмент журнала.

## Требования к презентации

- Включите как минимум один технический пример по теме: фрагмент конфигурации или кода, последовательность команд либо схему с конкретными параметрами. Объясните назначение основных элементов примера.
- Опишите ожидаемый результат и способ его проверки. Демонстрация с запуском приложения во время выступления рекомендуется. Допускается разбор подготовленного примера с пояснением ожидаемого результата. Развёртывание на публичном сервере не требуется.
- Укажите источники и версии инструментов, использованных в примере. Для технических сведений опирайтесь на официальную документацию.
- Используйте учебные значения секретов и параметры тестовой среды в примерах и иллюстрациях.

**Внимание:** использование телефона во время выступления, а также чтение текста со слайдов или сторонних источников без демонстрации реального понимания материала снижает оценку. Оценивается владение темой: умение отвечать на вопросы, объяснять код своими словами и обосновывать решения в конкретном сценарии.

## Темы презентаций

| № | Тема | Суть и цель раскрытия темы |
|---|---|---|
| 1 | Сборка и запуск Spring Boot из JAR | Собрать исполняемый JAR с помощью Maven или Gradle. Привести команду запуска и пояснить, как в архиве размещаются классы и зависимости. |
| 2 | Конфигурация приложения для разных сред | Подготовить профили dev и prod. На примере порта и адреса базы данных объяснить, как изменять настройки без пересборки приложения. |
| 3 | Управление секретами при развёртывании | Показать, как передать пароль базы данных через переменную окружения или подключаемый файл. Объяснить, где хранить секрет и как избежать его вывода в журнал. |
| 4 | Запуск Java-приложения как службы Linux | Подготовить unit-файл systemd. Объяснить настройку автозапуска и перезапуска, привести пример проверки состояния службы и просмотра журнала. |
| 5 | Упаковка Spring Boot приложения в Docker | Подготовить Dockerfile для готового JAR. Привести команды сборки и запуска, пояснить назначение базового образа и публикацию порта. |
| 6 | Многоэтапная сборка Docker-образа | Разделить сборку приложения и подготовку среды выполнения на два этапа. Сопоставить состав и размер одноэтапного и многоэтапного образов. |
| 7 | Запуск Spring Boot и PostgreSQL через Docker Compose | Подготовить compose.yaml для приложения и базы данных. Объяснить обращение к БД по имени сервиса и сохранение данных в томе. |
| 8 | Публикация и версионирование Docker-образов | Описать маркировку и публикацию образа в GitHub Container Registry или Docker Hub. Привести пример загрузки и запуска выбранной версии по тегу. |
| 9 | Автоматическая сборка и тестирование в GitHub Actions | Подготовить workflow для сборки проекта и запуска тестов при открытии или обновлении pull request. Показать, как сохранить JAR в качестве артефакта сборки. |
| 10 | Автоматическое развёртывание в тестовую среду | Описать этап доставки артефакта после успешной сборки. Предложить проверку доступности приложения и способ подтвердить номер развёрнутой версии. |
| 11 | Развёртывание Spring Boot на облачной платформе | Выбрать платформу и описать запуск приложения из репозитория или контейнерного образа. Указать, где задаются параметры подключения к БД и просматриваются журналы. |
| 12 | Обратный прокси для Spring Boot с Nginx | Привести пример конфигурации Nginx. На схеме показать путь запроса от клиента через прокси к приложению и объяснить назначение передаваемых заголовков. |
| 13 | Настройка HTTPS для Java-приложения | На схеме указать, где завершается TLS-соединение и как используется сертификат. Привести пример перенаправления с HTTP на HTTPS и способ проверки результата. |
| 14 | Проверки состояния через Spring Boot Actuator | Объяснить различие между работоспособностью процесса и готовностью принимать запросы. Привести примеры ответов проверки состояния при доступной и недоступной БД. |
| 15 | Журналы приложения в среде развёртывания | Показать настройку уровней журналирования. По фрагменту журнала службы или контейнера объяснить, как определить причину ошибки запуска. |
| 16 | Мониторинг приложения с Prometheus и Grafana | Выбрать метрики запросов, ошибок и памяти JVM. Объяснить на примере панели, как интерпретировать изменение метрик при росте нагрузки. |
| 17 | Ограничение ресурсов Java-приложения в контейнере | Привести пример задания лимитов CPU и памяти. Объяснить связь между лимитом памяти контейнера и максимальным размером кучи JVM. |
| 18 | Обновление приложения с изменением схемы БД | На примере добавления столбца описать порядок миграции и выпуска приложения. Указать, при каких условиях предыдущая версия сможет работать с новой схемой. |
| 19 | Резервное копирование и восстановление PostgreSQL | Привести команды создания резервной копии и восстановления в отдельную БД. Предложить способ проверить целостность и доступность данных после восстановления. |
| 20 | Обновление и откат версии приложения | Описать обновление с одной версии на другую, контрольную проверку и условие возврата. Привести последовательность действий для восстановления предыдущей версии. |

## Полезные ресурсы

**Книги:**

- Spring Boot: Up and Running — Mark Heckler
- Docker: Up & Running — Sean P. Kane, Karl Matthias
- Continuous Delivery — Jez Humble, David Farley

**Онлайн-ресурсы:**

- [Spring Boot Reference](https://docs.spring.io/spring-boot/) — упаковка приложения, внешняя конфигурация и Actuator.
- [Docker Documentation](https://docs.docker.com/) — образы, многоэтапная сборка и Docker Compose.
- [GitHub Actions Documentation](https://docs.github.com/actions) — автоматизация сборки, тестирования и развёртывания.
- [Документация systemd](https://www.freedesktop.org/software/systemd/man/latest/systemd.service.html) — описание служб Linux.
- [Документация Nginx](https://nginx.org/en/docs/) — обратный прокси и HTTPS.
- [PostgreSQL Documentation](https://www.postgresql.org/docs/) — резервное копирование и восстановление.
- [Prometheus Documentation](https://prometheus.io/docs/) и [Grafana Documentation](https://grafana.com/docs/) — сбор и визуализация метрик.
