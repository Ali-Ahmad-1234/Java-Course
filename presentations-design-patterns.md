# Темы презентаций: Паттерны проектирования

Этот раздел содержит темы групповых презентаций, посвящённых классическим паттернам проектирования (GoF) и связанным архитектурным концепциям. Каждая тема рассчитана на группу из 2–3 студентов.

## Общая информация

| Параметр | Значение |
|---|---|
| Формат работы | Групповая презентация (2–3 человека) |
| Продолжительность выступления | 10–15 минут |
| Количество слайдов | 15–25 слайдов |
| Язык презентации | Русский |
| Формат файла | PDF или PPTX |

**Важно:** все участники группы должны принимать участие в выступлении и быть готовы ответить на вопросы по любой части презентации.

## Требования к презентации

- Обязательны примеры кода на двух языках — C++ и Java (пара эквивалентных реализаций для каждого паттерна, чтобы показать различия в идиомах: шаблоны и RAII в C++ vs generics и сборка мусора в Java)
- Необходимо чётко объяснить сценарии применения: конкретные задачи и контексты, где паттерн уместен; признаки необходимости его использования; случаи, когда паттерн избыточен (over-engineering); реальные примеры из промышленных библиотек (STL, Boost, Qt для C++; JDK, Spring, Hibernate для Java)
- Для каждого паттерна обязательно раскрыть: назначение, структуру, участников, применимость, плюсы и минусы
- Рекомендуется показать анти-пример (код без паттерна) и рефакторинг к целевому паттерну

**Внимание:** использование телефона во время выступления, а также чтение текста со слайдов или сторонних источников без демонстрации реального понимания материала снижает оценку. Оценивается владение темой: умение отвечать на вопросы, объяснять код своими словами и обосновывать выбор паттерна в конкретном сценарии.
